# Yoga and Pilates Studio Class Management Bot

Telegram bot for yoga studios and Pilates instructors managing class bookings, student attendance, and membership renewals. Students book classes, receive confirmation and pre-class reminders, join waitlists for full sessions, and check their attendance history via bot commands. Instructors see real-time class rosters, mark attendance, and send post-class session notes. Studio managers get weekly revenue and attendance digest, membership expiry alerts 30 days out, and new student welcome sequences. Supports drop-in, pack, and monthly membership payment tracking. Integrates with Stripe for payment confirmation.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
